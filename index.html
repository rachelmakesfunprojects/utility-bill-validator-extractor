Utility Bill Extractor

Drop utility-bill PDFs to pull the account name, account number, service address, and billing postal code. Everything runs in your browser — no files are uploaded anywhere.

Cells are editable — click any value to correct it before downloading. The extraction is heuristic, so double-check unusual bills. Use text on a row to see exactly what was read from the PDF. Highlighted values need checking against the bill: look-alike letters from a scan were changed to digits (for example S → 5), the city wasn't printed and was filled in from the utility, or the billing postal code had to be guessed. Hover to see why. Editing a value clears its highlight.
